# Security policy

Please **do not** open a public issue for security problems.

Report them privately through GitHub: **Security → Report a vulnerability** on this
repository. If that isn't possible, message the team in the support server
(https://discord.gg/XEubrrkBmB) and ask for a private channel.

Include what you found, how to reproduce it and what an attacker could do with it.
We'll reply as soon as we can and credit you in the fix if you'd like.
